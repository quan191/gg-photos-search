# Changelog

## 0.1.0 - Chrome Developer Preview

- Added single filename search for the currently open Google Photos page.
- Added visible-photo scanning, highlighting, and optional broader metadata loading.
- Added secondary batch filename search for up to 100 unique filenames.
- Added local-only privacy and permission documentation.
- Added Chrome Developer Mode installation and troubleshooting instructions.
- Added tests, release validation, deterministic ZIP packaging, and GitHub Actions CI.

Known limitations:

- The Chrome Web Store listing is not available.
- Shared albums are the primary tested workflow.
- Google Photos DOM and internal request changes may break compatibility.
